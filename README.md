📝 Task Management System

A command-line Task Management System built with Python. This project helps users organize tasks, manage task queues, track completed tasks, and undo previous actions.

✨ Features

- **Add Task:** Create a new task.
- **Update Task:** Change an existing task's name.
- **Remove Task:** Delete a task using its ID.
- **Show All Tasks:** Display all available tasks.
- **Add Task to Queue:** Add a task to the waiting queue.
- **Complete Next Task:** Complete the first task in the queue.
- **Undo:** Restore the previous task and queue state.
- **Show Queue:** Display all tasks waiting to be completed.

🛠️ Technologies & Concepts

- Python 3
- Functions and modules
- Lists and dictionaries
- Linked List
- Queue (FIFO)
- Stack (LIFO)
- Exception handling

🧠 Data Structures

Queue (FIFO)
First In, First Out. The first task added to the queue is the first one completed.

Stack (LIFO)
Last In, First Out. Used to keep previous states for the Undo feature.

Linked List
Used to organize completed tasks through linked nodes.

This project was created to improve Python programming skills and understand how data structures work in real applications.

It provides practical experience with Lists, Dictionaries, Functions, Modules, Linked Lists, Queues, Stacks, and program flow.
